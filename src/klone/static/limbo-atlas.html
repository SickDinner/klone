Atlas E3 · pysyvä julkinen tutkimusmuisti

Yksittäinen hakukierros voi nähdä samat julkaisut uudelleen. E3:n erillinen Termuxissa sijaitseva SQLite-arkisto tunnistaa uudet tutkimusviitteet, muuttuneen julkaisumetadatan ja jo tunnetut viitteet. Se ei muuta KLONEn yksityistä Memory Corea eikä todenna tutkimusväitteitä oikeiksi.

Muistiarkiston tilaa ei ole vielä tuotu. Tietoja ei haeta tietokannasta selaimen taustalla.

Ota täysi 26 lähteen arkistointi käyttöön

cd ~/klone-arxiv-e1
STAMP="$(date +%Y%m%d-%H%M%S)"

PYTHONPATH="$PWD/src" "$HOME/klone-next/.venv/bin/python" \
  -m klone.limbo_atlas --fetch --all \
  --memory-db "$HOME/klone-var/atlas-memory.sqlite3" \
  --memory-delta-output "$HOME/klone-var/atlas-e3-delta-$STAMP.json" \
  --output "$HOME/klone-var/atlas-e3-briefing-$STAMP.json"

Nämä komennot suoritetaan vain itse käynnistettyinä. Tallennus säilyttää myös ne kelvolliset julkaisut, jotka eivät mahdu 48 havainnon neuvostoraporttiin. Tuo tämän jälkeen E3-muutostiedosto yllä olevalla painikkeella.

Atlas E4 · koko tutkimusarkiston työjono

Kaikki E3-arkiston julkaisuviitteet jaetaan enintään 48 havainnon eriin. Aiemmat 147 viitettä muodostavat neljä erää (48 + 48 + 48 + 3). Jokainen tutkimusala saa vuorollaan paikan neuvoston käsittelyjonossa.

E4-työjonoa ei ole vielä tuotu.

Erän lataaminen ei vielä merkitse tutkimusta tehdyksi. Valitse sen jälkeen alta rinki ja tutkimuskysymys ja paina "Luo ja reititä tutkimusluonnokset". Tarkistamatta olevia väitteitä ei julisteta tosiksi.

Vie koko arkiston jono Termuxista

cd ~/klone-arxiv-e1

PYTHONPATH="$PWD/src" "$HOME/klone-next/.venv/bin/python" \

cp "$HOME/klone-var/atlas-e4-queue-$STAMP.json" \

Atlas E5 · KLONEn älymuisti

Atlas E3:n julkiset julkaisuviitteet voidaan tuoda erikseen KLONEn varsinaiseen Memory Coreen. Niistä syntyy rajattuja, auditoituja ja alkuperäisjulkaisuun jäljitettäviä muistihavaintoja research-room-huoneeseen. Julkaisun väite ei muutu todistetuksi faktaksi.

Tutkimusmuistiin ei ole tehty hakua. E5-tuonti on käynnistettävä erikseen omistajan Termux-komennolla.

Esikatsele ensin, tuo sitten julkiset viitteet

cd ~/klone-arxiv-e1

PYTHONPATH="$PWD/src" "$HOME/klone-next/.venv/bin/python" \
  -m klone.limbo_memory_bridge \
  --atlas-db "$HOME/klone-var/atlas-memory.sqlite3" \
  --klone-db "$HOME/klone-var/arxiv-e1.db"

# Kun esikatselu näyttää oikean kohdetietokannan:
PYTHONPATH="$PWD/src" "$HOME/klone-next/.venv/bin/python" \
  -m klone.limbo_memory_bridge \
  --atlas-db "$HOME/klone-var/atlas-memory.sqlite3" \
  --klone-db "$HOME/klone-var/arxiv-e1.db" --commit

Tämä lisää vain E3-arkiston julkisia lähdemetatietoja omistajan käskystä. Se ei avaa käyttäjän yksityisiä muisteja, muuta suojattuja huoneita tai nosta epävarmoja väitteitä vahvistetuksi tiedoksi. Älymuistin yksittäisen löydön voi avata Memory Coren omassa kontekstinäkymässä.

Atlas E6 · Neuvoston tutkimusäly

Tutkimusäly hakee KLONEn oikean Memory Coren research-room-huoneesta, vertailee aiemmin tallennettuja lähteitä ja muodostaa jokaiselle tieteenalalle uusia testattavia tutkimuskysymyksiä. Se tarkistaa myös mahdolliset vastakkaiset sanamuodot, mutta ei väitä ristiriitoja todistetuiksi.

Odotetaan tutkimuskysymystä. Ei automaattista verkon lukua tai muistikirjoitusta.

Tämä versio tekee toistettavaa avainsana- ja lähdevertailua. Ristiriitasignaalit ovat tutkimuskysymyksiä, eivät tekoälyn toteamia tosiasioita. Alkuperäiset tutkimukset, menetelmät ja mahdollinen vertaisarviointi pitää edelleen tarkastaa.

4. Valitse vastaanottava rinki ja tutkimuskysymys

Automaattireititys käyttää alan luontevaa neuvostorinkiä. Vaihtoehtoisesti voit ohjata koko havaintojoukon valitsemaasi rinkiin ja pyytää uutta näkökulmaa.

Suunnitelmaa ei ole laadittu.

5. Hae uusia tutkimuksia Termuxissa

Ulkomaailman aineiston haku käynnistyy vain Termuxin --fetch-valinnalla. Voit hakea kaikki 26 lähdettä tai yhden tutkimusalan kerrallaan.

cd ~/klone-arxiv-e1

PYTHONPATH="$PWD/src" "$HOME/klone-next/.venv/bin/python" \
  -m klone.limbo_atlas \
  --fetch --domain genetics \
  --domain mind_medicine \
  --output "$HOME/klone-var/atlas-genetiikka-psykiatria.json"

Haku voi kestää useita minuutteja etenkin kaikilla lähteillä. Yhden lähteen estot tai tyhjät vastaukset säilyvät virheraportissa; niitä ei korvata keksityillä tutkimuksilla.

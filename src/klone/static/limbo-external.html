Lähteistetty yhteydenotto – vain luonnos

Agentti voi kirjoittaa asiantuntijalle tai yhteisölle kysymyksen omalla nimimerkillään. Luonnos kertoo vastaanottajalle, että kirjoittaja on automaattinen tutkimusagentti. Omistajaa tai KLONEn sisäisiä tietoja ei sisällytetä.

Mitään viestiä ei lähetetä automaattisesti.





Julkisen tutkimuksen käynnistäminen Termuxissa

  
RSS/Atom-lähteiden verkkoluku käynnistyy vain erillisellä --fetch-komennolla. API ja tämän sivun avaus eivät tee verkkohakuja kohdesivustoihin.

  
cd ~/klone-next
PYTHONPATH=src .venv/bin/python -m klone.limbo_external \
  --fetch --source arxiv-ai \
  --output "$HOME/klone-var/limbo-ai-report.json"

  
Lataa tehty JSON raporttiin yllä olevasta ”Tuo havainto-JSON” -valinnasta. Jokainen tuotu lähde säilyy epävarmana, kunnes sille tehdään erillinen lähdetarkistus.
